# Contributing to Alterbrain

Thank you for helping. Before you send a change, please read this short page.

## How to contribute

- Open an issue first for anything larger than a fix, so we can agree the approach.
- Follow the contracts in `docs/SPEC.md` and `.claude/rules/framework-dev.md`: zero-dependency Node scripts, tests with `node --test "tests/**/*.test.mjs"`, `node system/scripts/validate.mjs` clean, and plain UK English for anything a user reads.
- Never include personal data about a real person, client material or secrets. Use the example personas in `framework-dev.md`.
- Third-party content needs its licence notice and an entry in `THIRD_PARTY_NOTICES.md` and `UPSTREAM-SYNC.md`.
