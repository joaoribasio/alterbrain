# McKinsey 7S

**Definition:** Seven linked elements of an organisation (Strategy, Structure, Systems, Shared values, Skills, Style, Staff) that must fit together for the firm to perform.

## When to use / when not to
- Use it to diagnose why a plan is not working.
- Use it before a merger, a restructure or a big change.
- Do not use it to choose a strategy. It tests fit, not direction.
- Do not use it as a list of departments.

## Inputs you need
- Strategy documents and goals.
- Organisation chart, processes, IT and reporting.
- Interviews or survey data on culture and behaviour.

## Step-by-step
1. Draw the model. Put **Shared values** at the centre.
2. Describe the three "hard" elements: Strategy, Structure, Systems.
3. Describe the four "soft" elements: Shared values, Skills, Style, Staff.
4. Compare the **current** state with the **target** state for each.
5. Mark gaps and misfits between elements.
6. Rank the gaps by impact.
7. Plan actions that move several elements together.

## Common pitfalls (what professors mark down)
- Listing the seven words with a sentence each and no gaps.
- Treating soft elements as less important.
- Changing one element (for example, structure) and ignoring the others.
- Describing only today's state.
- No evidence for claims about culture.

## Worked example (synthetic)
A Dutch retailer wants to move from stores to online.

| Element | Today | Target |
|---|---|---|
| Strategy | Store-first | Online-first |
| Structure | Store managers lead | Cross-functional digital teams |
| Systems | Weekly sales reports | Live data dashboards |
| Shared values | "Know your customer face to face" | "Test and learn" |
| Skills | Merchandising | Data and UX |
| Style | Top-down | Team-led |
| Staff | 90% store staff | New digital hires plus retraining |

Biggest gap: systems and skills lag the new strategy. First action: dashboards and a training plan, before restructuring.

## Questions to ask yourself
- Which elements contradict each other today?
- Which element is the slowest to change?
- Do leaders model the new values?
- What is the first move that shifts several elements at once?
