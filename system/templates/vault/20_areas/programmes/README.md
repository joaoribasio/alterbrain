# Programmes

One note per programme (a degree, an MBA, a certificate track), named as you say it, for example `MBA – RSM`.

- Each note holds the facts that are true for every course in the programme: school or provider, level, start and end, terms, the programme-wide AI rule, the grading scale, how work is submitted and career services.
- Courses link to their programme with a `programme` property, so a course note repeats only what differs. A course from a provider such as Coursera has no programme note and names its provider instead.
- Alterbrain makes a programme note when you set up a course and give it the programme details. Everything in it is optional, and nothing is guessed.
