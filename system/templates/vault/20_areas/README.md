# Areas

Long-running parts of your life.

- `courses/` has one folder per course.
- `programmes/` has one note per programme (a degree, an MBA, a certificate track) with the facts that hold for all its courses. A standalone course, such as one from Coursera, has none.
- `career/` has your career targets, applications and CV.
