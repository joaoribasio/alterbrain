# Sources

Every file you give Alterbrain is copied here, untouched, so answers can point back to it.

- `raw/` holds the untouched copies. Never edit these.
- `text/` holds the readable text pulled out of each file.
- `notes/` holds one short note per source: what it is and where it came from.
- `manifest.jsonl` is the ledger of everything added (Alterbrain creates it).
