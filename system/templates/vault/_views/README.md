# Views

Saved Obsidian Bases views. Each `.base` file is a live table built from your notes. They show on [[Home]]. You do not need to edit them. `Contacts.base` lists the people in `60_people` with their next follow-up. `Routines.base` lists your scheduled jobs in `90_routines` with their last run.
