# Extra fonts

Drop font files (`.ttf`, `.otf`) into this folder and your documents will find them. You do not need to install them on your computer.

Use this when your brand file names a font that is not installed. Check what is missing with:

```
node system/quarto/tools/fonts.mjs
```

Only add fonts you are allowed to use and share. Font files you add here are copied into your private repository, so check the font's licence first. If in doubt, install the font normally (double-click it, then choose Install) and leave this folder empty.
