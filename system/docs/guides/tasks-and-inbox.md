# Tasks and inbox

You have **one** to-do list: `vault/00_inbox/Tasks.md`. Alterbrain adds items when it needs you. You add your own too.

## What a task looks like

```
- [ ] Review reply to Prof. Smith #ab/reply 📅 2026-10-09 🔼 [[2026-10-08 Reply to Prof Smith]]
```

- `- [ ]` is a checkbox. Tick it (`- [x]`) when done.
- `#ab/reply` means Alterbrain added it, and which skill did. Tasks without `#ab/` are yours.
- `📅 2026-10-09` is the due date.
- `⏫` high, `🔼` medium, `🔽` low priority.
- `[[…]]` links to the thing to look at. Click it in Obsidian.

## The sections

| Section | Use it for |
|---|---|
| Inbox | New items land here (Alterbrain always adds here) |
| Today | What you'll do today |
| This week | Later this week |
| Waiting on others | You're waiting for a reply |
| Someday | Ideas, no date |
| Done (archive weekly) | Finished items; the weekly review tidies them |

Move lines between sections whenever you like.

## When Alterbrain adds a task

Only when it needs you:
- a draft is ready to review;
- a proposal for a new skill needs your yes or no;
- it has a question before it can start;
- it found a deadline (for example in a syllabus);
- study cards are due;
- a setup step is waiting;
- something failed (for example the backup).

It does not add tasks for news or "FYI".

## The inbox folders

- `00_inbox/outbox/`: drafts waiting for you (emails, letters, posts). Read, edit, then send yourself. The task links to each one.
- `00_inbox/proposals/`: one-page proposals for new skills. Say yes or no in chat.
- `00_inbox/captures/`: quick notes you made with "capture this…" or "remind me…".

## Handy requests

- "What's due this week?"
- "Remind me to book the study room on Thursday." (adds a task with a date)
- "I've done the reply to Prof. Smith." (ticks it)
- "Run my weekly review." (tidies the list, archives done items, checks proposals)

## In Obsidian

`Home.md` shows Overdue, Due today, Next 7 days and "Alterbrain needs you". This needs the **Tasks** plugin, which setup installs. See [Using Obsidian](using-obsidian.md).
